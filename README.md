# Naval Engineering 0.2.0

Судостроение, ходовые испытания и экипаж на движущемся корпусе. Соберите собственное судно из блоков или спустите один из двух готовых проектов.

## Установка

1. Запустите **Minecraft Java 1.21.1** с **Java 21** и **Fabric Loader 0.20.1**.
2. Положите `naval-engineering-0.2.0.jar` и [Fabric API 0.116.18+1.21.1](https://maven.fabricmc.net/net/fabricmc/fabric-api/fabric-api/0.116.18%2B1.21.1/fabric-api-0.116.18%2B1.21.1.jar) в `mods`. При обновлении замените JAR 0.1.0.
3. Для сетевой игры установите 0.2.0 и Fabric API на сервере и обоих клиентах. Формат сохранённого корпуса версии 0.1.0 читается в 0.2.0.

[Установщик Fabric](https://fabricmc.net/use/installer/)

## Готовые суда

Откройте мир с разрешёнными командами. Для быстрого испытания подходит суперплоский мир с предустановкой **Water World**. Подойдите к глубокой воде. Оставьте свободное место для корпуса и несколько блоков над его рубкой.

| Команда | Судно |
| --- | --- |
| `/naval demo ~ ~ ~18 meridian` | **«Северный Меридиан»**. 27-метровое экспедиционное судно с высоким носом, остеклённой ходовой рубкой, мачтой, кормовой палубой, краном и машинным отделением. |
| `/naval demo ~ ~ ~18 squall` | **«Шквал»**. 17-метровый портовый буксир с двумя трубами, короткой рубкой и балластным килем. |

Команда без имени спускает «Северный Меридиан». Для спуска рядом двух судов оставьте между их центрами не менее 30 блоков. Команда сообщает фактические координаты спуска.

## На борту

- **Подняться на борт** можно правой кнопкой по корпусу на расстоянии взаимодействия или приземлением на открытую палубу. Нажатие выбирает подходящую точку опоры в пределах досягаемости. Обычное приземление работает после выключения полёта в творческом режиме.
- **Ходьба** использует привычные **W/A/S/D**, **Space** и клавишу бега. **Shift** замедляет ходьбу и удерживает у края. Чтобы сойти, пройдите за край палубы или перепрыгните фальшборт.
- **Управление** включается **R** возле штурвала внутри рубки. В этом режиме **W/S** дают тягу, **A/D** поворачивают. Ещё одно нажатие **R** возвращает ходьбу, оставляя игрока на борту.
- **Машинное отделение** находится под кормовой палубой. Спускайтесь по центральному трапу между жёлтыми панелями. Для подъёма вернитесь по трапу, удерживая движение вперёд. На одноярусной ступени игрок автоматически начинает короткий прыжок, если есть место над головой.
- **Два игрока** могут находиться на одном судне. Пока один управляет, второй может двигаться через двери, ходить по палубе и спускаться вниз. До восьми игроков могут быть на борту одновременно.
- **Погода и графика** проверяются командами `/weather thunder` и `/weather clear`. **O** меняет пресет визуализации воды.

## Свой корпус

Используйте доски, клёпаную обшивку, окрашенные панели, разрешённые блоки остекления, железный балласт и судовое оборудование. Поставьте ровно один блок штурвала. Нос направлен к отрицательному Z. В рубке предусмотрите твёрдый пол и два свободных блока по высоте. Незамкнутый проход или трап требует сплошной палубы вокруг и опоры ступеней. Замкнутые отсеки задаются закрытой оболочкой и переборками.

- `/naval inspect <x> <y> <z>` по координатам штурвала показывает массу, осадку, водоизмещение, запас плавучести, остойчивость и оценку скорости.
- `/naval launch <x> <y> <z>` собирает корпус, связанный гранями со штурвалом. Отсоедините его от стапеля и оставьте свободное место под килем.
- `/naval inspect` без координат показывает телеметрию судна. `/naval refuel` заправляет баки.
- `/naval breach 0 -7 0` открывает пробоину в днище «Северного Меридиана». `/naval repair 0 -7 0` закрывает её, если в проёме нет человека. Координаты в таких командах локальные.
- Для изменения мира командами спуска, пробоины, ремонта и заправки нужны права оператора уровня 2.

Лимит проекта **1280 блоков**, **29 блоков по каждой оси** и **2048 внутренних клеток**. При спуске действует лимит в восемь судов в области на 128 блоков от точки спуска по каждой оси.

## Сборка и испытания

Укажите JDK 21 в `JAVA_HOME`. Первая сборка загружает Gradle, Minecraft и зависимости.

| Действие | Windows | Linux / macOS |
| --- | --- | --- |
| Собрать мод и запустить JUnit | `gradlew.bat build` | `./gradlew build` |
| Игровые тесты | `gradlew.bat runGametest` | `./gradlew runGametest` |
| Клиент разработчика | `gradlew.bat runClient` | `./gradlew runClient` |

Готовый мод появляется в `build/libs/naval-engineering-0.2.0.jar`. Инструкция для сетевого испытания, критерии и ограничения движения описаны в `docs/DECK.md`. Архив также содержит модели физики и дорожную карту.

Каюты и трапы реализованы геометрией движущегося корпуса. Отдельный инвентарь судна, открывающиеся двери и функциональное управление краном остаются следующими этапами. Сетевая проверка выполнена на локальном TCP-сервере. Разные сетевые задержки, потеря пакетов и совместимость с другими модами движения требуют отдельных испытаний.
