# Naval Engineering 0.1.0

Инженерная сборка для Minecraft Java 1.21.1. Постройте корпус из блоков, рассчитайте осадку и остойчивость, спустите его на воду и проверьте, как он ведёт себя под тягой, на волне и после пробоины.

## Установка

1. Выберите профиль **Minecraft Java 1.21.1** с **Java 21** и **Fabric Loader 0.20.1**.
2. Положите `naval-engineering-0.1.0.jar` и [Fabric API 0.116.18+1.21.1](https://maven.fabricmc.net/net/fabricmc/fabric-api/fabric-api/0.116.18%2B1.21.1/fabric-api-0.116.18%2B1.21.1.jar) в папку `mods`.
3. На выделенном сервере установите те же версии Minecraft, Fabric Loader, Fabric API и мода. Мод и Fabric API нужны также каждому клиенту.

[Установщик Fabric](https://fabricmc.net/use/installer/)

## Первый выход

1. Создайте испытательный мир в творческом режиме с разрешёнными командами. Подойдёт открытое море или суперплоский мир с предустановкой **Water World**.
2. Встаньте рядом со свободным участком воды глубиной от четырёх блоков и выполните `/naval demo ~ ~ ~12`. Команда укажет место спуска двухотсечного судна.
3. Нажмите правой кнопкой по штурвалу. В творческом режиме можно сразу занять место командой `/ride @s mount @e[type=naval_engineering:ship,sort=nearest,limit=1]`.
4. Удерживайте **W** или **S** для переднего или заднего хода. **A/D** отклоняют тягу движителя. После отпускания клавиши дизель сбрасывает обороты, судно идёт по инерции. **Shift** освобождает место, **O** меняет детализацию воды.
5. Выполните `/weather thunder` для проверки в волнении. Команда `/naval breach -1 -3 3` открывает пробоину в днище кормового отсека демонстрационного судна. Наблюдайте за показаниями воды и крена на мостике. `/naval repair -1 -3 3` закрывает пробоину, трюмный насос продолжает откачку при наличии топлива.

Графические режимы Low, Medium, High и Ultra меняют радиус и шаг сетки. В режиме Simulation остаётся физика моря и стандартное изображение воды.

## Свой корпус

- Поставьте один блок штурвала (`naval_engineering:helm`) поверх палубы. Нос направлен к отрицательному Z. Координаты блоков относительно штурвала используются в инженерном отчёте и командах пробоины.
- Используйте доски, клёпаную обшивку, железные блоки для балласта и судовое оборудование. Отсек образуется из пустых клеток внутри оболочки. Закройте днище, борта и палубу. Сплошная переборка делит отсек на два.
- Поставьте дизель, бак и кормовой движитель. Движитель работает при погружении. Бак поставляется с 250 л, насос питается от этого же запаса. Несколько двигателей и движителей увеличивают доступную тягу.
- Команда `/naval inspect <x> <y> <z>` проверяет проект по координатам штурвала. Отчёт показывает массу, центр тяжести, осадку на ровном киле, требуемое водоизмещение, запас объёма, поперечную и продольную метацентрические высоты и оценку скорости.
- Отсоедините корпус от стапеля и посторонних конструкций из тех же материалов. Команда `/naval launch <x> <y> <z>` собирает разрешённые блоки, которые связаны гранями со штурвалом. Они переходят из мира в движущийся корпус. Для спуска оставьте свободное пространство под килем.
- `/naval inspect` без координат показывает телеметрию ближайшего судна или судна, которым вы управляете. `/naval refuel` заполняет его баки. Для спуска, демонстрации, пробоин, ремонта и заправки на сервере нужны права оператора уровня 2.

Лимиты проекта составляют **512 блоков**, **19 блоков по каждой оси** и **1024 внутренних клетки**. При спуске действует лимит в восемь судов в области на 128 блоков от точки спуска по каждой оси. Груз в первом выпуске представлен блоками балласта, которые размещаются до спуска.

## Сборка из исходников

Укажите JDK 21 в `JAVA_HOME`. Первая сборка загружает Gradle, Minecraft и зависимости.

| Действие | Windows | Linux / macOS |
| --- | --- | --- |
| Сборка и тесты симулятора | `gradlew.bat build` | `./gradlew build` |
| Серверные GameTest | `gradlew.bat runGametest` | `./gradlew runGametest` |
| Клиент разработчика | `gradlew.bat runClient` | `./gradlew runClient` |

Готовый мод появляется в `build/libs/naval-engineering-0.1.0.jar`. Отчёт JUnit лежит в `simulation/build/reports/tests/test/index.html`, отчёт GameTest в `build/gametest/reports/naval-gametest.xml`. Папку `tools` используют только для пересоздания исходных звуков и текстур. Готовые ресурсы входят в исходный архив.

## Границы выпуска

На движущемся судне доступно фиксированное место у штурвала. Ходьба по палубе, экипажи, доки как игровые механизмы, редактор с графической разметкой, другие типы силовых установок и расширенная навигация остаются в дорожной карте. Океан рисуется локальной сеткой над стандартной водой Minecraft. Отражения, пена и подводные эффекты сейчас приближённые или используют ванильный рендер. Проверены клиент с локальным сервером и серверный GameTest. Нагрузочный прогон и сеанс с несколькими сетевыми клиентами остаются непроверенными.

Подробности в файлах `docs/PHYSICS.md`, `docs/ARCHITECTURE.md` и `docs/ROADMAP.md` исходного архива.
